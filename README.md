# Dork Bot

My own take on Grok Bot. AI teammates you message like people. Each bot has a job, its own memory and routines, and bots can work together in group chats. Everything runs locally on **Dork**, my local model in Ollama.

This is a personal project, built for me. Feel free to fork it.

## Milestone 1

- Bot list: create, rename and pick an avatar
- One chat per bot
- Memory per bot
- Group chat with @-mentions
- Routines (scheduled tasks per bot)
- All of it on Dork (Ollama, local)

Status: planning.
